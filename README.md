# Golbarg plant content

Update packs for the [Golbarg](https://github.com/fardin-huma/golbarg) plant-care app.
The app checks `manifest.json` and downloads `plants.json` when there is newer content.

Served by GitHub Pages at https://fardin-huma.github.io/golbarg-content/manifest.json. Generated by `tools/publish_content.py`; don't edit by hand.

## Sources and licenses

- Full care guides (species, problems, symptoms): written for Golbarg. Drafts are marked
  `"reviewed": false` until checked by a person.
- Basic species: names and families from [Wikidata](https://www.wikidata.org/) (CC0); short
  summaries from [Wikipedia](https://www.wikipedia.org/) (CC BY-SA 4.0). Each entry links to its
  source article in `articles`.
